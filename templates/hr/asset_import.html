Import Instructions
Expected Excel Format

The header row is auto-detected (looks for "Asset Name", "Serial No.", etc. in the first 5 rows). The following columns are recognized:

Column Name Maps To Required
Asset Name Asset Name Required
Asset Type Asset Type Optional
Serial No. / Serial Number Serial No. Optional
Specifications Specifications Optional
Invoice Number Invoice Number Optional
Employee Name Employee Name Optional
Department Department Optional
Designation Designation Optional
Handover Date Handover Date Optional
Handover By Handover By Optional
Condition Condition (New/Used) Optional
Return Date Return Date (free text) Optional
Return To Return To Optional
QTY / Quantity Quantity Optional
Purchase Date Purchase Date Optional
Price (SAR) / Price Price Optional
Planned Asset Life Planned Life Optional
In Stock? In Stock (Yes/No) Optional
Tips:
  • Rows without an Asset Name will be skipped.
  • Existing assets (matched by Asset Name + Serial No.) will be updated.
  • Re-importing the same file is safe and will update existing records.
  • The header row is expected at row 2 (row 1 may contain section groupings).
