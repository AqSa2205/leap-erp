Import Instructions
Expected Excel Format

The header row is auto-detected (looks for "NAME" or "S/No." in the first 5 rows). The following columns are recognized:

Column Name Maps To Required
IQAMAH/PASSPORT / Iqama Iqama/Passport No. Required
NAME / Full Name Full Name Required
DESIGNATION Designation Optional
QUALIFICATION Qualification Optional
DATE OF BIRTH Date of Birth Optional
JOINING DATE Joining Date Optional
NATIONALITY Nationality Optional
Marital Status Marital Status (Single/Married) Optional
BLOOD GROUP Blood Group Optional
Email / Work Email Work Email Optional
DOCUMENTS Documents Link Optional
DEPLOYMENT Deployment Optional
Contract type Contract Type (Permanent/Yearly/AJEER) Optional
Mobile No Mobile Number Optional
Tips:
  • Rows without a Name or Iqama/Passport number will be skipped.
  • Existing employees (matched by Iqama/Passport) will be updated.
  • Re-importing the same file is safe and will update existing records.
